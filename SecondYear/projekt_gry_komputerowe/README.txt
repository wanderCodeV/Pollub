# Górskie Rozgrywki - Projekt zaliczeniowy
Strona internetowa poświęcona grom komputerowym z motywami górskimi.

## Opis projektu
Projekt przedstawia trzy gry: Wiedźmin 3: Dziki Gon, The Elder Scrolls V: Skyrim oraz Celeste. 
Strona zawiera recenzje, galerię screenów, formularz rekrutacji, quiz sprawdzający wiedzę oraz dashboard do śledzenia sesji gier.

## Struktura projektu

- index.html - Strona główna z sekcjami: opis strony, geolokalizacja, quiz, ciekawostki
- info.html - Opisy gier i ankieta preferencji
- reviews.html - Recenzje gier w formie karuzeli Bootstrap
- gallery.html - Galeria screenów z filtrowaniem i modalnym podglądem
- rekrutacja.html - Formularz rekrutacji z zapisem do localStorage
- dashboard.html - Dashboard do śledzenia sesji gier
