# Programowanie aplikacji internetowych

Rozwiązania zadań laboratoryjnych z przedmiotu **Programowanie aplikacji internetowych** (Politechnika Lubelska, Wydział Elektrotechniki i Informatyki, kierunek Informatyka).

## Spis zajęć (laboratoriów)

1. **Laboratorium 1** `📅07.10.2026` – Środowisko programistyczne aplikacji internetowej – serwer Apache, MySQL i PHP. Podstawy tworzenia aplikacji PHP.
2. **Laboratorium 2** `📅21.10.2026` – Obsługa formularzy w PHP. Tablice globalne.
3. **Laboratorium 3** `📅27.10.2026` – Praca z plikami i katalogami.
4. **Laboratorium 4** `📅04.11.2026` – Filtry i walidacja danych.
5. **Laboratorium 5** `📅13.10.2026` – Projektowanie oraz tworzenie klas dla zadanego problemu. Praca z plikami XML i JSON.
6. **Laboratorium 6** `📅18.11.2026` – Praca z danymi w PHP i MySQL. Realizacja klasy do obsługi bazy danych w oparciu o rozszerzenie mysqli lub PDO. Stworzenie prostej aplikacji typu CRUD.
7. **Laboratorium 7** – Implementacja mechanizmu sesji w aplikacjach PHP. Zastosowanie ciasteczek.
8. **Laboratorium 8** – Obsługa rejestracji i logowania użytkownika.
9. **Laboratorium 9** – Implementacja mechanizmów zabezpieczeń przed popularnymi atakami na aplikacje internetowe.
10. **Laboratorium 10** – Modułowy szablon strony w oparciu o definicję klasy zarządzającej wyglądem strony.
11. **Laboratorium 11** – Asynchroniczna transmisja danych z serwera z wykorzystaniem PHP, AJAX i jQuery.
12. **Laboratorium 12** – Implementacja wzorca projektowego MVC w przykładowej aplikacji typu CRUD (Laravel).
13. **Laboratorium 13** – Prezentacja projektów.

## Technologie

- PHP
- MySQL / phpMyAdmin
- HTML / CSS / JavaScript (Fetch API, AJAX, jQuery)
- XML / JSON
- Laravel
- XAMPP (Apache)
