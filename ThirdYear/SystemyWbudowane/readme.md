# Systemy wbudowane

Rozwiązania zadań laboratoryjnych z przedmiotu **Systemy wbudowane** (Politechnika Lubelska, Wydział Elektrotechniki i Informatyki, kierunek Informatyka).

## Spis zajęć (laboratoriów)

1. **BHP** `📅09.10.2026`
2. **Laboratorium 1** `📅16.10.2026` – Porty wejścia/wyjścia (GPIO) oraz obsługa klawiatury matrycowej w mikrokontrolerach AVR (ATmega32).
3. **Laboratorium 2** `📅23 & 30.10.2026` – Komunikacja ze sterownikiem wyświetlacza alfanumerycznego LCD HD44780 (tryb 4-bitowy, pamięć DDRAM/CGRAM).
4. **Laboratorium 3** `📅06.11.2026` – Transmisja szeregowa z wykorzystaniem sprzętowego modułu USART (polling oraz przerwania).
5. **Kolokwium** `📅20.11.2026`
